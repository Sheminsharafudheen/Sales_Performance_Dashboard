# Sales Performance Dashboard

## Project Overview
This project analyzes sales data to identify business trends, profitable product categories, regional performance, and loss-making subcategories.

## Tools Used
- Python — data cleaning and analysis
- Pandas — data processing
- MySQL — database storage and SQL analysis
- Power BI — interactive dashboard and visualization

## Dataset
Sample Superstore dataset containing 9,994 sales records.

## Key Business Insights
- **Total Sales:** $2,297,200.86
- **Total Profit:** $286,397.02
- **Total Quantity Sold:** 37,873
- **Total Orders:** 5,009
- **Unique Customers:** 793
- **Profit Margin:** 12.47%

## Analysis Performed
- Sales and profit by category
- Regional sales performance
- Profit by product subcategory
- Identification of loss-making subcategories
- Monthly sales and profit trends

## Project Structure
- `data/raw/` — original dataset
- `data/processed/` — cleaned data and analysis outputs
- `sql/` — SQL analysis queries
- `powerbi/` — Power BI project materials
- `screenshots/` — dashboard screenshots

## Conclusion
This project demonstrates an end-to-end data analytics workflow, from data cleaning and SQL analysis to business insights and Power BI visualization.
